# Mercury —— 然然的温度计小伙伴

一个放在书桌上的语音陪伴宠物：立创·实战派 ESP32-S3 开发板 + 阿里云上的自建服务 + DeepSeek 大模型。

```
 然然说话
    │
 ┌──▼───────────────────┐   WebSocket（Opus 音频）   ┌───────────────────────────────┐
 │ 立创实战派 ESP32-S3   │ ─────────────────────────▶ │ 阿里云服务器（Docker）          │
 │ 固件：xiaozhi-esp32   │                            │  nginx 网关（密钥路径把门）      │
 │ 麦克风/喇叭/屏幕/摄像头│ ◀───────────────────────── │  xiaozhi-esp32-server           │
 └──────────────────────┘   语音 + 表情指令           │   语音识别 → DeepSeek → 语音合成 │
                                                      └───────────────────────────────┘
```

| 目录 | 内容 |
|---|---|
| `server/` | 服务端：一键部署脚本、配置模板、人设提示词、网关 |
| `character/` | Mercury 的形象：6 套形态 × 21 个表情的生成器（默认 `mercury`，按参考图绘制） |
| `firmware/` | 固件：配置片段和编译烧录脚本；`firmware/board/` 是 Mercury 自己的板型代码（竖屏、电量显示、触摸互动），`firmware/sounds/` 是触摸时的短音效 |

## 一、部署服务端

1. 打开 `server/.env`，把 DeepSeek 的 Key 填到 `DEEPSEEK_API_KEY=` 后面。
   建议同时填 `DASHSCOPE_API_KEY`（阿里云百炼）：有它才有童声、流式低延迟，而且 2核2G 的服务器就够；
   不填则用本地语音识别（需要 4G 内存）和没有童声的 EdgeTTS。
   Token Plan / 业务空间的百炼 Key 还要填 `DASHSCOPE_BASE_URL`（控制台给的专属地址）。
   部署脚本会把两套语音通路都真实跑一遍并打印结果，自动选能用的：
   - 流式通路（`paraformer-realtime-v2` + `cosyvoice-v2`）：普通百炼 Key 可用，有童声、延迟低
   - 原生 HTTP 通路（`qwen-audio-3.0-asr-flash` + `qwen-audio-3.0-tts-plus`）：Token Plan 套餐用这一套，
     由 `server/providers/` 里两个自己写的模块对接；这个模型没有童声，音色在 `.env` 的 `QWEN_TTS_VOICE` 里改
   - 都不行：EdgeTTS 合成；识别退回本地 FunASR（需要约 4G 内存，不够就直接报错停下）
2. 把 `server` 目录传到服务器并运行部署脚本。这台电脑上有一把项目专用的免密密钥
   `~/.ssh/mercury_deploy_ed25519`（不想再用时，从服务器的 `~/.ssh/authorized_keys` 里删掉
   以 `mercury-deskrobot-deploy` 结尾的那一行）：

   ```
   scp -i $env:USERPROFILE\.ssh\mercury_deploy_ed25519 -r F:\WorkSpace\DeskRobot\server root@<服务器IP>:/opt/
   ssh -i $env:USERPROFILE\.ssh\mercury_deploy_ed25519 root@<服务器IP> "cd /opt/server && bash deploy.sh"
   ```

3. 在阿里云控制台的安全组里放行入方向 TCP `18080`。

以后改了 `.env`、人设或配置，重新执行上面两条命令即可（同名文件会被覆盖，服务器上的记忆和音乐不受影响）。

- 看对话日志：`docker logs -f xiaozhi-esp32-server`
- 放儿歌：把 mp3 放进服务器的 `/opt/server/music/`，说"放一首小星星"

## 二、编译并烧录固件

ESP-IDF v6.1 已装在 `F:\Espressif`（固件 v2.6.0 不再支持 5.x）。在 cmd 或 PowerShell 里（不要用 Git Bash）：

```
cd F:\WorkSpace\DeskRobot
firmware\idf-env.cmd python firmware\build_firmware.py
```

`idf-env.cmd` 负责设置编译环境，后面跟什么命令就执行什么。板子接在 `COM11`（烧录）和 `COM12`（日志）。

常用参数：

- `--orientation portrait|portrait-180|landscape`：屏幕方向，默认 `portrait` 竖屏，
  喇叭和摄像头朝上立着放（已在板子上确认）；如果换了外壳、画面倒了，改用 `portrait-180`
  （板子逆时针转 90° 放）；`landscape` 回到原来的横屏。摄像头画面会跟着一起转正
- `--camera-rotate 0|90|180|270`：只有拍照预览的方向不对时才需要，单独指定摄像头画面的旋转角度
- `--battery-gpio 10 --battery-divider 2.0`：电池分压接的引脚和分压比（见下面"电量显示"）；`--battery-gpio none` 关掉
- `--phase glass|warm|frost|star|rainbow`：换一套形态，默认是 `mercury`（换形态需要重新烧录）
- `--wake xiaozhi`：唤醒词退回"你好小智"
- `--wake-pinyin "ni hao mo ke rui" --wake-threshold 20`：调自定义唤醒词
- `--no-flash` 只编译；`--flash-only` 不重编、直接烧录上次的结果

看板子的日志：

```
firmware\idf-env.cmd python firmware\serial_log.py
```

如果板子没存过 Wi-Fi，重启后会进入配网：手机连上 `Xiaozhi-` 开头的热点，在弹出的页面里选家里的 Wi-Fi。服务器地址已经编进固件，不用填。

### 电量显示

屏幕右上角会显示电池图标和百分比，但立创实战派**本身没有电池电路**，固件需要一根线才能读到电池电压：

- 电池正极（充放电模块上的 `BAT+`）→ 100kΩ → 扩展口的 `GPIO10` → 100kΩ → `GND`
- `GPIO10` 在板子的多功能扩展口（5P GH 端子）上，也是这块板上唯一空闲的 ADC1 引脚
- 两只电阻静态耗电约 20µA，对 2000mAh 电池可以忽略

没接这两只电阻时固件会自动隐藏电量（不会乱显示）。接好后串口日志每分钟打印一次
`BatteryGauge: Battery 3.912V ...`，可以拿万用表量一下电池电压对照；差得多就调 `--battery-divider`。
没有接充电状态信号，所以充电时只会看到电量往上涨，不显示闪电图标。电量降到 0% 时会弹出"请充电"并提示一声。

注意：板子的配置区（NVS）里如果存着以前设置的服务器地址，它会盖过固件内置的地址。
这块板子遇到过一次，处理办法是读出配置区、用 `firmware/nvs_remove_key.py` 删掉 `wifi:ota_url` 再写回，原始备份在 `firmware/generated/nvs-backup*.bin`。

### 触摸互动

屏幕是触摸屏，规则只有一条：**按住是"我要说话 / 不说了"，点和摸是跟它玩**。

| 动作 | 待机时 | 聆听时 | Mercury 说话时 |
|---|---|---|---|
| 点一下（点头、点身体） | 换表情，有时说"嘿嘿""好痒呀"；快速连点会头晕 | 眨眨眼，不结束对话 | 换一秒表情，不打断 |
| 来回摸 | 眯眼、爱心眼，说"好舒服呀"；连续摸满 2 秒，Mercury 会开口回应（5 分钟最多一次） | 眯眼、爱心眼 | 换一秒表情，不打断 |
| 按住约 1 秒 | 开始对话（"叮"一声） | 结束对话 | 打断它，转成听你说 |

- 待机 5 分钟没人说话、没人摸，Mercury 会犯困；再过 1 分钟屏幕调暗。摸一下就醒，唤醒词照常能用
- 顶部状态栏不响应触摸；开机、配网、升级时触摸也不响应
- 触摸时的短音效在 `firmware/sounds/`，是用 Mercury 现在的音色合成的。想换句子就改 `firmware/make_sounds.py`
  里的 `CLIPS`，按它开头的说明在服务器上重新生成，再重新编译烧录
- 摸头开口时，设备会给服务器发一句"【摸摸头】"，人设提示词里说明了它的意思，所以屏幕字幕上会看到这几个字
- 手势的时长、距离、睡觉时间等参数都在 `firmware/board/mercury_touch.h` 开头
- 串口日志里每次触摸都有一行 `MercuryTouch: down (x,y) zone=...`

### 养成：然然陪 Mercury 长大

核心玩法是**然然当小老师**：她教 Mercury 一个知识、一个新词、一首儿歌、一个游戏怎么玩，Mercury 会谢谢她、
用自己的话复述一遍并记下来，以后聊天时偶尔提起"你教过我……"。另外还有三个好习惯小约定：早上说早安、
告诉它喝了水、晚上说晚安（说完晚安它就去睡觉）。

- **小星星**：每天来找 Mercury 玩得 1 颗，教新东西每件 1 颗（每天最多 3 颗），每个小约定 1 颗。
  所以一天最多 7 颗，玩得久不会长得快
- **配饰**：攒够 5 / 15 / 30 / 50 / 80 颗星星，依次得到小红花、星星徽章、毛线帽、彩虹徽章、小皇冠，
  得到时自动戴上，Mercury 会开心地说出来。头上、身上各戴一件，可以说"换上小红花""把帽子摘下来"
- **心情温度**：Mercury 身上的红色水银柱就是今天的心情温度。每天从同一个高度开始，点一点、摸一摸能让它涨
  （摸最多涨到七成），聊天、教它东西、做到小约定涨得更多
- **只开心不难过**：几天没玩，星星、配饰、记住的东西一样都不会少，水银柱也不会降，Mercury 只会说"好想你呀"。
  提示词里也写明了不催她、不说"你要每天来"

给家长：

- 成长记录在服务器的 `/opt/server/data/mercury_growth/<设备>.json`，里面有星星数、她教过的每一件事和日期、配饰。
  可以直接看；改数字或删掉文件（从头开始）后，下次连上来就生效
- 不想要养成：把 `server/config.template.yaml` 里 `mercury_learned`、`mercury_habit`、`mercury_dress` 三行删掉，重新部署
- 记录哪些算"教东西"由大模型判断，偶尔会漏记或多记；住址、电话、家人和幼儿园名字被要求不记
- 代码：服务端 `server/plugins/mercury_growth.py`，配饰的画法在 `character/gen-faces.mjs` 的 `ACCESSORIES`，
  板子上的显示在 `firmware/board/mercury_growth.h` 和 `mercury_display.h`。星星门槛和每天上限在插件开头，
  心情温度涨多少在 `mercury_growth.h` 开头
- 没有板子时测试：`node server/selftest.mjs "我教你，蜗牛背着房子慢慢爬"`，会打印服务器推给板子的成长状态
  （测试设备的记录也存在同一个目录，文件名以 `AA_BB_CC` 开头，可以删）

## 三、调整 Mercury

| 想改什么 | 改哪里 |
|---|---|
| 性格、说话方式、安全规则 | `server/config.template.yaml` 里的 `prompt:` 一段 |
| 回复长度、表情、工具等通用规则 | `server/prompt/mercury-prompt-template.txt` |
| 声音 | `server/config.template.yaml` 里 `AliBLTTS` 的 `voice` |
| 孩子的称呼 | `server/.env` 的 `CHILD_NAME` |
| 形象 | `character/gen-faces.mjs`，改完 `npm run build`（同时出横屏用的 160px `png/` 和竖屏用的 224px `png-portrait/`）；也可以直接换成自己画的 21 张同名 PNG |

## 目前的状态与已知限制

已验证（2026-11-14）：

- 服务端：容器启动、网关的密钥路径把门、OTA 接口、WebSocket 握手；DeepSeek 能正常回话
- 固件：编译、烧录成功；板子启动后连上 Wi-Fi、向我们的服务器完成激活并进入待机
- 资源包里是 21 张 Mercury 表情，唤醒模型加载成功，自定义唤醒词已注册
- 200 万像素摄像头（GC2145）被识别并初始化

- 服务端语音链路：用 `server/selftest.mjs` 模拟设备提问，大模型回话并合成出语音，首段语音约 1.9 秒；
  识别接口单独验证过（把合成的音频送回去能原样识别）

- 真实设备上的整条链路：对着板子说"你好 Mercury"能唤醒，说话被识别，Mercury 回话并出声
- 屏幕上的 Mercury 显示正常（家长确认）
- 摄像头看图：板子拍照、上传、服务器看图、念出结果，整条通路实测通过（看图约 7 秒，比平时对话慢）。
  最初失败是因为外部内存不够，`build_firmware.py` 里的源码补丁把屏幕图片缓存的预留从 3.5MB 缩到约 2MB 后解决；
  固件现在每 10 秒打印一次 `free psram`，待机时约 1.6MB

**还没验证：**

- 唤醒词"你好 Mercury"到底灵不灵：芯片上的中文唤醒模型只认拼音，英文的 Mercury 用近似音"mo ke rui"代替，
  可能要调拼音和阈值；不行就先用 `--wake xiaozhi`
- 看图回答改成儿童口吻之后，还没在真实板子上再测过（只用测试图片验证了服务器这一段）

没有硬件时测试服务端：`node server/selftest.mjs "你是谁呀"`（模拟设备说一句话，看有没有文字和语音返回）。

固件侧的限制（上游固件对这块板子的支持现状）：

- 电量显示需要自己加两只分压电阻（见"电量显示"）；待机久了只会把屏幕调暗，Wi-Fi 和麦克风一直开着，2000mAh 电池的续航需要实测
- 触摸（2026-11-14 加的）：按住开始、打断、结束对话，点、摸、连点的表情已在板子上验证；
  竖屏方向是对的，但记到的竖直坐标最大只有 231（屏幕高 320），坐标可能没完全对准，点头和点身体的区分可能不准。
  音效、摸头开口、睡觉还没在板子上测过
- 竖屏（2026-11-14 加的）：方向已在板子上确认；拍照预览的方向、电量读数还待确认
- 表情只有协议规定的 21 种；形态是整包替换，不能在对话中途切换
- 养成（2026-11-15 加的）：在真板子上实测了"教它一件事 → 服务器记下 → 板子收到 → 水银柱上涨"；
  服务端用模拟设备测过早安小约定、攒满 5 颗解锁小红花、重复教同一件事不重复记、没解锁的配饰戴不上、摘下配饰。
  配饰在真板子屏幕上的样子、晚安小约定还没实测。配饰只给默认的 `mercury` 形态画了，换别的形态时不显示配饰和水银柱。
  服务端的插件挂在小智后端的提示词管理器上；后端镜像（`server_latest`）以后升级如果改了那部分，
  部署日志里不会出现"Mercury 养成已启用"，这时工具照常能用，只是提示词里看不到成长情况

## 给家长的几点说明

- 默认的 `mercury` 形象是照着别人创作的同人角色画的，家里自用没问题；如果要把这个项目或图片公开发布，
  请先征得原作者同意，或换成 `glass` 等原创形态。
- 然然说的话会经服务器转成文字发给 DeepSeek；填了百炼 Key 时，语音识别、语音合成和拍照看图走阿里云百炼。
  不填百炼 Key 时语音识别在你自己的服务器上完成。
- 记忆功能会把对话要点总结后存在你自己的服务器上，Mercury 靠它记得然然喜欢什么；
  不想要的话把 `server/config.template.yaml` 里的 `Memory: mem_local_short` 改成 `Memory: nomem`。
- 提示词里写了儿童安全规则，但大模型不是百分之百可靠，建议头几天陪着一起玩，并不时看看对话日志。
- 服务没有 HTTPS，访问控制靠地址里的随机密钥；如果域名已备案，后续可以加证书。
